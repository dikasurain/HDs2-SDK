# 数码管亮度增强方案（备用）

> 当默认高亮样式（深色底板 + 荧光绿 + 辉光）仍不够亮时，按见效程度依次尝试以下方案。

---

## 当前已应用的基础配置

| 项 | 值 | 位置 |
|----|----|------|
| 深色底板 | `#0A1A0E` 圆角（116×42） | `MainWindow.xaml` 数码管后 |
| 段填充 | `#00E676` 荧光绿 | `SevenSegmentDigit.xaml` Style |
| 段辉光 | `DropShadowEffect #00FF66` blur 14 | `SevenSegmentDigit.xaml` Style |
| 熄灭段不透明度 | `0.04` | `SevenSegmentDigit.xaml.cs` |

---

## 备用激进方案

### 方案 1：Bloom 模糊光晕层（最有效）

在数码管**背后**放大号绿色椭圆，用 `BlurEffect` 重度模糊，模拟 LED 强光外溢。
`BlurEffect` 与段自带的 `DropShadowEffect` 分属不同元素，互不冲突。

```xml
<!-- 放在深色底板之后、数码管 StackPanel 之前 -->
<Ellipse Width="140" Height="60" Fill="#6600FF66"
         HorizontalAlignment="Center" VerticalAlignment="Center">
    <Ellipse.Effect>
        <BlurEffect Radius="20"/>
    </Ellipse.Effect>
</Ellipse>
```

调节杠杆：
- `Fill` 的 alpha 越大光晕越浓（`#66` → `#99`）
- `Radius` 越大光晕越散（20 → 28）

---

### 方案 2：段芯径向渐变（高光内核）

把段填充从纯色改成"白绿芯 → 绿边"，模拟 LED 灯丝中心更亮。

```xml
<Setter Property="Fill">
    <Setter.Value>
        <RadialGradientBrush GradientOrigin="0.5,0.5">
            <GradientStop Color="#FFCCFFE0" Offset="0"/>   <!-- 近白绿芯 -->
            <GradientStop Color="#FF00E676" Offset="0.6"/>
            <GradientStop Color="#FF00B85A" Offset="1"/>   <!-- 深绿边 -->
        </RadialGradientBrush>
    </Setter.Value>
</Setter>
```

---

### 方案 3：整个表盘内部涂黑

不只给数码管加小底板，给整个圆环内侧加深色圆，最大化绿色对比。
半径控制在刻度内端以内，避免盖住刻度。

```xml
<Ellipse Width="116" Height="116" Fill="#FF06120A"
         HorizontalAlignment="Center" VerticalAlignment="Center"/>
```

---

### 方案 4：嵌套多层辉光（突破单 Effect 限制）

WPF 每个元素只能有一个 `Effect`，但可套多层 `Grid`，每层各加一个递增 blur 的 `DropShadowEffect`。

```xml
<Grid>
    <Grid.Effect>
        <DropShadowEffect Color="#FF00FF66" BlurRadius="24" ShadowDepth="0" Opacity="0.6"/>
    </Grid.Effect>
    <Grid>
        <Grid.Effect>
            <DropShadowEffect Color="#FF00FF66" BlurRadius="12" ShadowDepth="0" Opacity="0.9"/>
        </Grid.Effect>
        <local:SevenSegmentDigit .../>
    </Grid>
</Grid>
```

---

### 方案 5：OuterGlowBitmapEffect（核武器，慎用）

已废弃但 WPF 仍可用，光晕比 `DropShadowEffect` 更厚实。
缺点：软件渲染，性能差，仅建议静态或少量元素使用。

```xml
<Polygon.Effect>
    <OuterGlowBitmapEffect GlowColor="#00FF66" GlowSize="12" Opacity="0.9"/>
</Polygon.Effect>
```

---

## 推荐组合

**方案 1（Bloom 椭圆）+ 方案 2（段芯渐变）** 叠加后，数码管会有明显的"发光体"质感，远超单纯改颜色。

|--------|------|

| `#AAFF00` | 柠檬绿（接近真实 LED） |

| `#0A1A0E` | 深绿黑底板（当前使用） |
| `#06120A` | 更深的纯黑绿（方案 3） |
