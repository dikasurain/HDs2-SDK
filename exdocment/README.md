# CRC Modbus 通讯程序

## 功能
该程序实现了CRC16 Modbus协议通讯，用于发送命令和接收数据。

## 主要功能
1. CRC16 Modbus算法实现
2. 串口通讯（COM1）
3. 发送命令：CE 05 10 12 A3
4. 循环接收数据

## 编译环境
需要支持Windows API的C编译器，如：
- Visual Studio
- MinGW

## 编译方法
### 使用MinGW
```bash
gcc Handshark_Test.c -o Handshark_Test.exe
```

### 使用Visual Studio
1. 打开项目
2. 配置为Win32控制台应用程序
3. 编译

## 运行注意事项
1. 修改COM端口号：根据实际情况修改代码中的"\\\\.\\COM1"为正确的串口
2. 检查串口参数：波特率9600，数据位8，校验位无，停止位1
3. 运行前确保设备已连接到电脑
4. 以管理员身份运行（Windows可能需要管理员权限访问串口）

## 命令说明
发送的命令包含：
- 前5个字节：0xCE 0x05 0x10 0x12 0xA3
- 后2个字节：CRC16 Modbus校验码（低字节在前）

## 接收数据
程序会循环接收从串口传来的数据并打印

## 错误处理
程序会输出详细的错误信息，如：
- 串口打开失败
- 参数设置失败
- 发送/接收失败
